# Quiz CLI 📚

An interactive command-line quiz game for learning and testing JavaScript knowledge. This project demonstrates modern JavaScript concepts including ES Modules, async/await, file system operations, and more.

## Features

- ✨ Interactive command-line interface
- 📋 Multiple-choice questions from JSON data
- 🎯 Real-time score tracking
- 🎨 Colored output with visual feedback
- ⚡ Built with modern JavaScript (ES Modules)
- 📚 Educational tool for learning JavaScript

## Project Structure

```
test-app/
├── index.js              # Main entry point
├── package.json          # Project metadata and dependencies
├── data/
│   └── questions.json    # Quiz questions database
└── src/
    ├── quiz.js           # Quiz class and logic
    ├── input.js          # User input handling
    └── colors.js         # Terminal color utilities
```

## Prerequisites

- Node.js 18.0.0 or higher
- npm or yarn

## Installation

1. Clone this repository:
```bash
git clone <repository-url>
cd test-app
```

2. Install dependencies:
```bash
npm install
```

## Usage

Run the quiz application:
```bash
npm start
```

Or directly with Node:
```bash
node index.js
```

## JavaScript Concepts Demonstrated

This project showcases the following JavaScript concepts:

- **ES Modules**: `import` and `export` statements
- **Async/Await**: Asynchronous operations with Promise handling
- **File System Operations**: Reading and parsing JSON files
- **Classes & OOP**: Quiz class implementation
- **Array Methods**: `map()`, `filter()`, `forEach()`
- **Destructuring**: Object and array destructuring
- **Template Literals**: String interpolation
- **Error Handling**: Try-catch blocks
